## 10. Matrici e Parentesi
Per le parentesi che si adattano all'altezza del contenuto, usa `\left` e `\right`.

Esempio: `\left( \frac{a}{b} \right)` -> $\left( \frac{a}{b} \right)$

**Matrici:**
```latex
\begin{matrix} a & b \\ c & d \end{matrix}      % Nessuna parentesi
\begin{pmatrix} a & b \\ c & d \end{pmatrix}    % Parentesi tonde
\begin{bmatrix} a & b \\ c & d \end{bmatrix}    % Parentesi quadre
\begin{vmatrix} a & b \\ c & d \end{vmatrix}    % Determinante (barre)
````

Resa:

$$\begin{pmatrix} a & b \\ c & d \end{pmatrix}$$

## 11. Sistemi di equazioni (Cases)

Snippet di codice

```
f(x) = \begin{cases} 
  x^2 & \text{se } x > 0 \\
  0 & \text{altrimenti}
\end{cases}
```

Resa:

$$f(x) = \begin{cases} x^2 & \text{se } x > 0 \\ 0 & \text{altrimenti} \end{cases}$$

## Parentesi Grandi 

In LaTeX (e quindi in Obsidian), il trucco per far sì che le parentesi si adattino automaticamente all'altezza della frazione è usare i comandi **`\left`** e **`\right`** prima dei simboli delle parentesi.

Senza questi comandi, le parentesi rimarrebbero piccole, risultando esteticamente sgradevoli accanto a una frazione.

### 1. Parentesi Tonde

Snippet di codice

```
\left( \frac{a}{b} \right)
```

**Resa:** $\left( \frac{a}{b} \right)$

---

### 2. Parentesi Quadre

Snippet di codice

```
\left[ \frac{a}{b} \right]
```

**Resa:** $\left[ \frac{a}{b} \right]$

---

### 3. Parentesi Graffe

_Nota: poiché le graffe hanno un significato sintattico in LaTeX, vanno precedute dal backslash `\`._

Snippet di codice

```
\left\{ \frac{a}{b} \right\}
```

**Resa:** $\left\{ \frac{a}{b} \right\}$

---

### 4. Altri delimitatori comuni

|**Tipo**|**Codice**|**Resa**|
|---|---|---|
|**Valore Assoluto**|`\left|\frac{a}{b} \right|
|**Norma**|`\left\| \frac{a}{b} \right\|`|$\left\\| \frac{a}{b} \right$|
|**Angolari**|`\left\langle \frac{a}{b} \right\rangle`|$\left\langle \frac{a}{b} \right\rangle$|

---

### 💡 Consiglio Pro: Parentesi solo da un lato

Se vuoi una parentesi grande solo a sinistra (ad esempio per un sistema o una valutazione), puoi usare il punto `.` per "chiudere" il comando `\left` senza mostrare nulla a destra:

Snippet di codice

```
\left( \frac{a}{b} \right.
```

**Resa:** $\left( \frac{a}{b} \right.$
