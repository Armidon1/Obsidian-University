# Surrogate Key

> [!summary] In short
> An artificial, meaningless integer key generated by the warehouse for dimension rows, instead of the natural key of the source systems.

- Isolates the warehouse from changes and conflicts in source codes (two sources may reuse the same `product_code`).
- Allows several versions of the same entity (history of attribute changes).
- Allows special members ("unknown", "not applicable") without NULL foreign keys.
- Compact integer → smaller fact table and faster joins.
- The natural key is kept as an ordinary attribute.
