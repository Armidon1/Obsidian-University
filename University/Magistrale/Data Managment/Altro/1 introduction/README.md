# Data Management Obsidian Vault

This package contains 45 atomic notes derived from `1-Introduction.pdf` and expanded for self-study.

Start from `00 - Data Management MOC.md`. Each note is designed to remain understandable on its own and contains links to the concepts that precede or extend it.

The notes are organized into:

- `01 - Foundations`
- `02 - Relational Algebra Operators`
- `03 - Query Patterns`
- `04 - SQL Core`
- `05 - Aggregation and Grouping`
- `06 - Window Functions`

Place the entire folder inside an Obsidian vault. Obsidian will resolve its internal wiki links automatically. If you also place `1-Introduction.pdf` at the vault root, the `source` property in every note becomes a direct backlink to the original material.
