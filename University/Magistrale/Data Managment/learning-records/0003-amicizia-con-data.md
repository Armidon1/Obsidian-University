# Amicizia come risorsa con data

Simone ha completato le quattro triple che rappresentano l'amicizia tra John e Mary con un unico blank node e una data literal `"2020-06-01"^^xsd:date`. Ha corretto, dopo feedback esplicito, sia l'introduzione superflua di un blank node per la data sia la direzione di `:participant`, inizialmente invertita e mantenuta nel primo tentativo di correzione: verificare il trasferimento a un nuovo esempio prima di considerare autonoma questa competenza.

Prossimo passo: verificare cosa identifica il blank node e se distingue le triple presenti nel grafo dalla tripla binaria di amicizia, che questo pattern non aggiunge automaticamente.
