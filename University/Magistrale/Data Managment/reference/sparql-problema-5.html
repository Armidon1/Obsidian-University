La query (5.2)

SELECT ?x
WHERE { ?x rdf:type :Classe . }

?x = posto vuoto. Ogni tripla del grafo che combacia dà una riga (omomorfismo pattern → grafo). a equivale a rdf:type.

Schema della giustificazione

  1. (a) Q(G) = ∅: G non contiene triple esplicite x rdf:type :C; il graph database usa solo le triple presenti.
  2. (b) Q(G) = {…}: per ogni individuo, cita le triple usate e la regola applicata.

Trappole viste negli appelli

  • Domain e range scambiati: il dominio tipizza il soggetto, il range l’oggetto.
  • Frase riportata («X has announced that…»): reificazione. La tripla descritta non è asserita, quindi non attiva regole.
  • «is also the name of» (aeroporto, virus): IRI diversa per ciascun individuo, stesso literal in :name.
  • «For every x, y, if x is painted by y, then x is created by y»: rdfs:subPropertyOf.
  • «Everyone who teaches is a Lecturer»: rdfs:domain sulla proprietà.
