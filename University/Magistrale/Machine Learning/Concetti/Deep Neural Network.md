# Deep Neural Network

> [!summary] In short
> A network with more than one hidden layer. Compared with shallow ones of the same size, deep networks produce many more linear regions and in practice train faster and generalise better.

- **Width** = units in a layer; **capacity** = total hidden units; **depth** = number of layers.
- No rule for width/depth: test.
- Feed-forward: layer $i$ connected only to layer $i+1$.
