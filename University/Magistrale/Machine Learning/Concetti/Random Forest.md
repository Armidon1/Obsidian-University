# Random Forest

> [!summary] In short
> Many short trees trained on different random subsets of the data (bagging, plus random feature subsets) combined by (weighted) majority vote: low bias, much lower variance than a single tree.

- An instance of **bagging** with trees as base models.
- Fights the overfitting of deep trees.
