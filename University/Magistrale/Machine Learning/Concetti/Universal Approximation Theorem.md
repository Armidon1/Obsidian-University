# Universal Approximation Theorem

> [!summary] In short
> A shallow network with a linear output and enough "squashing" (or ReLU) hidden units can approximate any Borel-measurable (e.g. continuous) function to arbitrary accuracy.

- Says it is **possible**, not how many units (possibly exponentially many) nor how to find the weights.
- Squashing function: $a:\mathbb{R}\to(a,b)$ (e.g. sigmoid).
