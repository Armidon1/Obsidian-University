# Tensor

> [!summary] In short
> Generalisation of arrays (1-D) and matrices (2-D) to more dimensions; e.g. an RGB image is a 3-D tensor height × width × channels. The basic data structure of TensorFlow/PyTorch.

- Convolutional layers with several channels are tensors.
- A batch of images is a 4-D tensor.
