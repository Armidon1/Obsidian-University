# Parametric vs Non-Parametric Models

> [!summary] In short
> Parametric models are defined by a fixed set of parameters learnt from the data (the data can then be discarded); non-parametric (instance-based) models use the dataset itself as the hypothesis, like kNN.

| | Parametric | Non-parametric |
|---|---|---|
| examples | linear/logistic regression, Perceptron, neural networks | kNN |
| memory | $\theta$ | whole dataset |
| work | at training | at inference |
