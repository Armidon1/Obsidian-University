# **Operando `mod`**

> `mod` (modulo) è un **operatore matematico** che restituisce il **resto della divisione intera** tra due numeri.

---
**Definizione:**  
$$C = M \bmod n  $$
Significa: dividi ( M ) per ( n ) e prendi **solo il resto** della divisione.

**Esempi pratici:**

1. ( $17 \bmod 5 = 2$ ) → perché ( $17 = 3 \cdot 5 + 2$ )
    
2. ( 2$0 \bmod 6 = 2$ ) → perché ($20 = 3 \cdot 6 + 2$ )
    

---

**In breve:**

> `mod` = **resto della divisione** → fondamentale in crittografia per **aritmetica modulare** su numeri grandi.
