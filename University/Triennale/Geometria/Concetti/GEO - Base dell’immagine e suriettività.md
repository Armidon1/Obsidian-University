# Base dell’immagine e suriettività

> [!summary] In breve
> Per una matrice rappresentativa $A$ di $f:V\to W$, le colonne generano l’immagine in coordinate. Una base si ottiene selezionando le colonne originali nelle posizioni dei pivot.

$$\dim\operatorname{Im}f=\operatorname{rk}A,\qquad f\text{ suriettiva}\iff\operatorname{rk}A=\dim W.$$

Se le basi non sono canoniche, le colonne sono coordinate e vanno interpretate nella base del codominio.
