# Estrazione di una base

> [!summary] In breve
> Da una famiglia di generatori in coordinate si estrae una base tramite Gauss: si dispongono i vettori per colonne, si individuano le colonne pivot e si selezionano le corrispondenti colonne della matrice **originale**.

Il numero dei vettori selezionati è il rango. Le operazioni di riga preservano le relazioni tra colonne, ma possono cambiare lo spazio delle colonne: non si usano le colonne trasformate come base dello spazio originale.
