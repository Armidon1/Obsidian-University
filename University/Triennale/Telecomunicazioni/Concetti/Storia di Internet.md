# Storia di Internet

> [!summary] In breve
> Dalla commutazione di pacchetto degli anni '60 (Kleinrock, Baran, Davies) ad ARPAnet (1969), a TCP/IP (1983), al Web (Berners-Lee, 1989–91) e all'Internet commerciale, mobile e cloud di oggi.

| Periodo | Tappe |
| --- | --- |
| 1961–1972 | teoria delle code per i pacchetti (Kleinrock); **ARPAnet**, primo IMP a UCLA (1969); NCP; prima e-mail (1972) |
| 1972–1980 | ALOHAnet, Telenet, Cyclades; Cerf e Kahn → *internetting*; TCP, IP e UDP separati; ALOHA → Ethernet |
| 1980–1990 | 1/1/1983 passaggio a **TCP/IP**; controllo di congestione; **DNS**; NSFNET; Minitel |
| anni '90 | fine di ARPAnet; NSFNET commerciale; **World Wide Web** (HTML, HTTP, server, browser); Netscape; bolla dot-com |
| 2000– | larga banda e fibra, Wi-Fi e 4G, social network, reti private dei content provider, cloud |
