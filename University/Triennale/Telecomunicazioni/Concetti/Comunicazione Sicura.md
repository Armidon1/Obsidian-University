# Comunicazione Sicura

> [!summary] In breve
> Una comunicazione è sicura se garantisce **riservatezza**, **integrità del messaggio** e **autenticazione** delle parti; per le reti delle organizzazioni si aggiunge la **sicurezza operativa** (firewall, IDS). L'intruso (Trudy) può intercettare, modificare, inserire e cancellare messaggi.

| Proprietà | Strumento |
| --- | --- |
| Riservatezza | cifratura (simmetrica, a chiave pubblica) |
| Integrità | hash crittografiche, MAC, firma digitale |
| Autenticazione | protocolli con nonce, certificati |
| Sicurezza operativa | firewall, IDS/IPS |

- Anche l'**infrastruttura** ne ha bisogno: DNS, tabelle di instradamento, gestione di rete.
- Sicurezza a ogni livello: applicazione (PGP), trasporto (SSL), rete (IPsec), collegamento (802.11i).
