# Mobilità nelle Reti Cellulari

> [!summary] In breve
> GSM usa l'instradamento indiretto: il corrispondente chiama l'**MSC di appartenenza**, che chiede all'**HLR** il numero di roaming (**MSRN**, simile al COA) e inoltra all'MSC visitato, che tiene gli utenti presenti nel **VLR**.

| GSM | IP mobile |
| --- | --- |
| home system | home network |
| home MSC + HLR | home agent |
| visited system | visited network |
| MSC visitato + VLR | foreign agent |
| MSRN | COA |

- Aggiornamento della posizione: il telefono si registra presso il VLR, che informa l'HLR.
