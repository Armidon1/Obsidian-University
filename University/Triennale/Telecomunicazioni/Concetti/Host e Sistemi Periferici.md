# Host e Sistemi Periferici

> [!summary] In breve
> Gli **host** (o **sistemi periferici**, *end system*) sono i dispositivi ai bordi della rete che eseguono le applicazioni: PC, server, smartphone, "cose" IoT. Si collegano a Internet tramite un ISP.

| Componente di Internet | Ruolo |
| --- | --- |
| **Host** | eseguono le applicazioni (client o server) |
| **Collegamenti** | trasportano i bit, velocità $R$ in bps |
| **Commutatori di pacchetto** | inoltrano i pacchetti: **router** (nucleo), **switch** (accesso) |

- **Client**: richiedono servizi. **Server**: li erogano, oggi soprattutto nei **data center**.
- Le applicazioni girano **solo sugli host**, non sui router.
- I programmi chiedono a Internet di consegnare dati tramite l'**interfaccia socket**.
