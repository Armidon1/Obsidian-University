# Reti di Accesso

> [!summary] In breve
> La **rete di accesso** collega fisicamente un host al suo **edge router**, il primo router sul percorso verso il resto di Internet.

| Tecnologia | Mezzo | Dispositivi chiave | Note |
| --- | --- | --- | --- |
| **DSL** | doppino telefonico | modem DSL, splitter, **DSLAM** in centrale | asimmetrica; 3 bande FDM (0–4 kHz voce, 4–50 kHz up, 50 kHz–1 MHz down); distanze brevi |
| **Cavo (HFC)** | fibra + coassiale | cable modem, nodo ottico, **CMTS** | asimmetrico; **mezzo condiviso** → serve accesso multiplo |
| **FTTH** | fibra fino a casa | **ONT**, splitter ottico, **OLT** (PON) | fino al Gbps; AON o PON |
| **Ethernet** | doppino | switch, router aziendale | LAN; 100 Mbps – 10 Gbps |
| **Wi-Fi** (802.11) | radio | access point | decine di metri; ~100 Mbps condivisi |
| **3G / LTE** | radio cellulare | stazione base | decine di km |
| Satellite / dial-up | radio / doppino | — | > 1 Mbps / 56 kbps |
