# x86-64

> [!summary] In breve
> Estensione a 64 bit di IA32: 16 registri a 64 bit (RAX…RBP, R8–R15), i primi 6 parametri nei registri RDI, RSI, RDX, RCX, R8, R9, suffisso `q` per i 64 bit.

- RAX ⊃ EAX ⊃ AX ⊃ AL; R8 ⊃ R8D ⊃ R8W ⊃ R8B; DIL e SIL esistono.
- **Scrivere i 32 bit bassi azzera i 32 alti** (`movl $1,%eax` azzera la parte alta di RAX).
- Dal settimo parametro in poi si usa lo stack.
- `movq`, `movsbq`; system call con l'istruzione `syscall` invece di `int $0x80`.
- `gcc -m32` per compilare in IA32.
