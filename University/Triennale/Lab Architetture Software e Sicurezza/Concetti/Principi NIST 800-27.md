# Principi NIST 800-27

> [!summary] In breve
> Principi di ingegneria della sicurezza del NIST SP 800-27 rev. A, in sei gruppi: Security Foundation, Risk Based, Ease of Use, Increase Resilience, Reduce Vulnerabilities, Design with Network in Mind.

| Gruppo | Principi chiave |
|---|---|
| Security Foundation | politica di sicurezza, sicurezza parte del design, sviluppatori formati |
| Risk Based | rischio accettabile, sistemi esterni insicuri, proteggere dati in uso/transito/riposo |
| Ease of Use | standard aperti, sicurezza usabile |
| Increase Resilience | sicurezza a strati, isolare i sistemi pubblici, audit, disaster recovery |
| Reduce Vulnerabilities | semplicità, **least privilege**, minimizzare ciò di cui fidarsi |
| Design with Network in Mind | autenticare utenti e processi, identità univoche |
