# Autenticazione a Due Fattori

> [!summary] In breve
> Verifica con due fattori di categoria diversa contemporaneamente, come password + telefono o bancomat + PIN.

- Una password rubata (phishing, data breach) non basta più all'attaccante.
- Due password non sono due fattori: servono categorie diverse (know / have / are).
