# Software as a Service

> [!summary] In breve
> Modello in cui il software gira sui server del fornitore e l'utente vi accede via rete con un browser o un'app.

**Vantaggi**: nessuna installazione, dati nel servizio, una sola copia del server, aggiornamenti trasparenti, collaborazione sugli stessi dati, dati grandi accessibili da remoto.

**Svantaggi**: serve la rete, dati in mano al fornitore, latenza, bersaglio centralizzato per gli attacchi.

Tecnologie: [[Modello Client-Server]], [[HTTP Request e Response]], [[REST]], [[Model-View-Controller]].
