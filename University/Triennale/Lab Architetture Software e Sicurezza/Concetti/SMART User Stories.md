# SMART User Stories

> [!summary] In breve
> Una buona user story è Specific, Measurable, Achievable, Relevant e Timeboxed.

| | Criterio | Esempio / regola |
|---|---|---|
| S | Specific | "cerca un film **per titolo**" |
| M | Measurable | "99% delle pagine entro 3 s", testabile |
| A | Achievable | una story per iterazione, altrimenti dividerla |
| R | Relevant | valore di business, chiedere "perché?" |
| T | Timeboxed | fermarsi allo sforamento e ridividere o ripianificare |
