# Architettura Software

> [!summary] In breve
> L'organizzazione complessiva di un prodotto software (componenti, server, tecnologie), che determina gli attributi di qualità non funzionali.

- Attributi: responsiveness, reliability, availability, security, usability, maintainability, resilience.
- **Impossibile ottimizzarli tutti**: trade-off tipici
  - maintainability vs performance (tanti componenti = più comunicazione);
  - security vs usability;
  - availability vs costi e time to market (ridondanza).
- Domande: come organizzare il sistema, come distribuire e far comunicare i componenti, quali tecnologie.
