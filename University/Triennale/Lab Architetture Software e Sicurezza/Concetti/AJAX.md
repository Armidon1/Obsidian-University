# AJAX

> [!summary] In breve
> Asynchronous JavaScript And XML: il JavaScript della pagina chiede dati (XML o JSON) al server senza ricaricare la pagina e la aggiorna da sé.

Evoluzione: web statico (1990) → pagine generate dal server (SaaS, 1995) → **AJAX** → web come insieme di servizi componibili ([[Service-Oriented Architecture]]).

Il client non riceve più pagine da mostrare ma **chiama funzioni remote** e riceve dati ([[JSON]]).
