# Cloud Computing IaaS PaaS SaaS

> [!summary] In breve
> Il cloud è un insieme di server remoti virtuali in affitto, scalabili ed elastici, offerti a tre livelli: infrastruttura, piattaforma e software.

| Livello | Il vendor gestisce | Esempio |
|---|---|---|
| IaaS | calcolo, storage, rete virtualizzati | Amazon EC2 |
| PaaS | + database, ambiente di sviluppo, gestione | Heroku |
| SaaS | tutta l'applicazione | Gmail |

Proprietà: **scalabilità**, **elasticità**, **resilienza**. Vedi anche [[1 - Cloud Computing, Virtualizzazione e Containerization]].
