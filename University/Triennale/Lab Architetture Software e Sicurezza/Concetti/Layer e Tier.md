# Layer e Tier

> [!summary] In breve
> Un layer è un raggruppamento logico di componenti (presentation, application, resource management); un tier è il modulo software che implementa un layer, tipicamente su una macchina distinta.

| Layer | Ruolo |
|---|---|
| Presentation | interazione con l'utente |
| Application logic | cosa fa il sistema |
| Resource management | organizzazione dei dati |

Layer = divisione **logica**; tier = divisione **fisica** di deployment.
