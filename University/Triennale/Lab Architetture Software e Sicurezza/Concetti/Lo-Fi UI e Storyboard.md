# Lo-Fi UI e Storyboard

> [!summary] In breve
> Sketch a mano a bassa fedeltà delle schermate e storyboard che li collega nel grafo delle interazioni dell'utente, prima di scrivere HTML.

- **Sketch lo-fi**: la UI in un istante, su carta; economico, coinvolge il cliente.
- **Storyboard**: albero o grafo di schermate guidato dalle scelte dell'utente.
- Poi HTML con `<div>` per i blocchi del layout, CSS minimo (Bootstrap) solo dopo che funziona.
