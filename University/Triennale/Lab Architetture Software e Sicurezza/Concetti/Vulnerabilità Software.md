# Vulnerabilità Software

> [!summary] In breve
> Le vulnerabilità vivono nelle funzionalità implementate ma non richieste né documentate: ciò che il software fa oltre i requisiti.

| Zona | Significato |
|---|---|
| requisiti ∩ implementato | feature |
| requisiti − implementato | bug |
| implementato − requisiti | funzionalità non volute → **vulnerabilità** |

Per questo vanno testati anche i sad path e i casi d'abuso, non solo i requisiti.
