# User Story

> [!summary] In breve
> Descrizione in 1–3 frasi informali di una funzionalità dal punto di vista dell'utente, nel template Connextra (ruolo, obiettivo, beneficio).

```
As a movie fan,
So that I can share a movie with other movie fans,
I want to add a movie to RottenPotatoes database
```

- Nate nella comunità HCI su schede 3x5.
- Devono essere testabili, implementabili in un'iterazione, con valore di business ([[SMART User Stories]]).
- Sostituiscono i documenti di design; diventano scenari [[Given When Then]].
