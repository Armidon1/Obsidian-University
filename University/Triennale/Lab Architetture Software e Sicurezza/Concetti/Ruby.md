# Ruby

> [!summary] In breve
> Linguaggio interpretato, tipizzato dinamicamente, in cui tutto è un oggetto e ogni operazione è una chiamata di metodo; è la base di Rails.

- Tutto è un oggetto → ogni operazione è un metodo (`5 + 3` è `5.+(3)`), ogni istruzione restituisce un valore.
- Variabili d'istanza accessibili da fuori solo tramite accessor.
- Strumenti: `ruby file.rb`, console `irb`, RVM per le versioni.
- Convenzioni: metodi `?` (booleani), `!` (modificano l'oggetto), `=` (setter); l'ultima espressione è il valore restituito.
- Zucchero sintattico: parentesi omettibili, graffe dell'hash finale omettibili.
