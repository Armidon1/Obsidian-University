# Project-based vs Product-based Software

> [!summary] In breve
> Il software project-based nasce dal problema di un cliente esterno che fissa i requisiti per contratto; quello product-based nasce da un'opportunità di mercato e i requisiti li decide lo sviluppatore.

| | Project-based | Product-based |
|---|---|---|
| Punto di partenza | problema del cliente | opportunità |
| Requisiti | cliente + sviluppatore | sviluppatore |
| Vincolo | contratto legale | time to market |

Storicamente si è passati dal primo al secondo: molte aziende avevano problemi comuni e non serviva software su misura.
