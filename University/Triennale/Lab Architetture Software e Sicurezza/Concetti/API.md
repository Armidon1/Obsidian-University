# API

> [!summary] In breve
> Application Programming Interface: il contratto tra chiamante e chiamato, che stabilisce operazioni disponibili, forma degli URI, errori e requisiti operativi.

- La documentazione dice quali operazioni ci sono, come costruire gli URI, come vengono riportati gli errori, i limiti (chiamate al giorno, API key).
- Quasi tutte le API richiedono **autorizzazione**, di solito con una **API key** nell'URI o nell'header `Authorization:` (un segreto da non pubblicare).
- Nel 2-tier l'API permette di integrare il sistema con altri.
