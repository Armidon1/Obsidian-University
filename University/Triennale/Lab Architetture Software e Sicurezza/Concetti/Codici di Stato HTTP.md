# Codici di Stato HTTP

> [!summary] In breve
> Il codice numerico della risposta HTTP indica l'esito: 2xx successo, 3xx ulteriore azione, 4xx errore della richiesta, 5xx errore del server.

| Classe | Esempi |
|---|---|
| 2xx successo | 200 OK, 201 Created |
| 3xx redirect | 301, 302 |
| 4xx client error | 400 Bad Request, 401 Unauthorized, 404 Not Found |
| 5xx server error | 500 Internal Server Error, 503 Service Unavailable |

In caso di errore il body spiega cosa è andato storto.
