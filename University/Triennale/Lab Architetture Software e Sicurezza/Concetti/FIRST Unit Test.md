# FIRST Unit Test

> [!summary] In breve
> I buoni unit test sono Fast, Independent, Repeatable, Self-checking e Timely.

| | Proprietà |
|---|---|
| F | veloci, si eseguono di continuo |
| I | indipendenti, in qualsiasi ordine |
| R | ripetibili, stesso risultato ogni volta |
| S | si verificano da soli |
| T | scritti insieme al codice (con il TDD, prima) |

[[Mock e Stub]] servono a renderli F, I e R.
