# Modelli di Esecuzione del Software

> [!summary] In breve
> Tre modi di eseguire un software: stand-alone (tutto sul computer dell'utente), ibrido (funzionalità divise), software as a service (sull'utente solo l'interfaccia).

| Modello | Computer dell'utente | Server del produttore |
|---|---|---|
| Stand-alone | UI, funzionalità, dati | aggiornamenti |
| Ibrido | UI, parte delle funzionalità, dati | altre funzionalità, backup, aggiornamenti |
| SaaS | UI (browser/app) | funzionalità, dati |
