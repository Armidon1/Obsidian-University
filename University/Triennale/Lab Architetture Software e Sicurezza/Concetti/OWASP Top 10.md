# OWASP Top 10

> [!summary] In breve
> Documento di consapevolezza di OWASP con i dieci rischi più comuni delle web app, ciascuno valutato per sfruttabilità, prevalenza, rilevabilità e impatto.

Edizione 2013 (quella del corso): A1 [[SQL Injection|Injection]], A2 [[Broken Authentication e Session Management]], A3 [[Cross-Site Scripting]], A4 [[Insecure Direct Object Reference]], A5 [[Security Misconfiguration]], A6 [[Sensitive Data Exposure]], A7 [[Missing Function Level Access Control]], A8 [[Cross-Site Request Forgery]], A9 [[Using Known Vulnerable Components]], A10 [[Unvalidated Redirects and Forwards]].

Percorso di un attacco: threat agent → attack vector → weakness → (control) → technical impact → business impact.

Edizione 2021: A01 Broken Access Control (= A4 + A7), A02 Cryptographic Failures, A03 Injection (con XSS)…
