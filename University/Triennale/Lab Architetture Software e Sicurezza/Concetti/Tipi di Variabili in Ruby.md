# Tipi di Variabili in Ruby

> [!summary] In breve
> In Ruby il tipo di variabile si legge dal nome: locale, @istanza, @@classe, Costante, $globale.

| Forma | Tipo |
|---|---|
| `foo` | locale |
| `@foo` | d'istanza |
| `@@foo` | di classe |
| `Foo`, `FOO` | costante / nome di classe |
| `$foo` | globale |

Sono tutte variabili distinte.
