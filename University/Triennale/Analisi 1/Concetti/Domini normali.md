# Domini normali

> [!summary] In breve
> Un dominio y-semplice è {a ≤ x ≤ b, g₁(x) ≤ y ≤ g₂(x)}, uno x-semplice {c ≤ y ≤ d, h₁(y) ≤ x ≤ h₂(y)}; sono i domini su cui si applica Fubini–Tonelli.

- **$y$-semplice**: ogni retta verticale lo taglia in un segmento $[g_1(x), g_2(x)]$.
- **$x$-semplice**: ogni retta orizzontale lo taglia in un segmento $[h_1(y), h_2(y)]$.
- **Regolare**: unione finita di domini semplici.
- In $\mathbb{R}^3$: $z$-semplice $= \{(x,y) \in D,\ g_1(x,y) \le z \le g_2(x,y)\}$.
- Lo stesso dominio può essere semplice in entrambi i modi: si sceglie quello che rende gli integrali più facili.
