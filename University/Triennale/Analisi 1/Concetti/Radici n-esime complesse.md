# Radici n-esime complesse

> [!summary] In breve
> Ogni w = r(cos ϑ + i sin ϑ) ≠ 0 ha esattamente n radici n-esime: zₖ = r^(1/n)(cos ϑₖ + i sin ϑₖ) con ϑₖ = (ϑ + 2kπ)/n, k = 0, …, n − 1.

$$z_k = \sqrt[n]{r}\left(\cos\frac{\vartheta + 2k\pi}{n} + i\sin\frac{\vartheta + 2k\pi}{n}\right), \qquad k = 0, \dots, n-1$$

- Sono i vertici di un **poligono regolare** di $n$ lati sulla circonferenza di raggio $|w|^{1/n}$.
- Esempio: $\sqrt[3]{i} = \frac{\sqrt3}{2} + \frac i2,\ -\frac{\sqrt3}2 + \frac i2,\ -i$.
- Radici quadrate di $-1$: $\pm i$; radici quarte di $1$: $1, i, -1, -i$.
