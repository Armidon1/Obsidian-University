# Norma euclidea

> [!summary] In breve
> ‖x‖ = √(x₁² + … + x_N²) è la lunghezza di un vettore di ℝᴺ; ‖x − y‖ è la distanza. Generalizza il modulo e serve a definire limiti e continuità in più variabili.

- $\|x\| \ge 0$, $\|x\| = 0 \iff x = 0$; $\|\alpha x\| = |\alpha|\|x\|$; $\|x + y\| \le \|x\| + \|y\|$.
- Per $N = 1$ coincide con il [[Valore assoluto]].
- Intorno circolare: $B_r(x_0) = \{\|x - x_0\| < r\}$.
- $x_n \to x_0 \iff \|x_n - x_0\| \to 0 \iff$ convergenza componente per componente.
- In coordinate polari $\|(x, y)\| = \rho$.
