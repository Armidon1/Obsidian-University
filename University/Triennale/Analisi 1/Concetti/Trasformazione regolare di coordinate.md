# Trasformazione regolare di coordinate

> [!summary] In breve
> Una funzione f : ℝᴺ → ℝᴺ di classe C¹ con det J_f ≠ 0 tranne in pochi punti singolari; è localmente invertibile con inversa regolare.

- **Teorema di invertibilità locale**: $\det J_f(x_0) \neq 0 \Rightarrow$ $f : U(x_0) \to V(y_0)$ invertibile, $J_{f^{-1}}(y) = J_f(x)^{-1}$.
- Lineare $f(x) = Ax$: invertibile (globalmente) $\iff \det A \neq 0$.

| Coordinate | $\det J$ | Punti singolari |
|---|---|---|
| polari | $\rho$ | origine |
| cilindriche | $\rho$ | asse $z$ |
| sferiche | $\rho^2\sin\varphi$ | asse $z$ |
