# Funzioni iperboliche

> [!summary] In breve
> cosh x = (eˣ + e⁻ˣ)/2, sinh x = (eˣ − e⁻ˣ)/2, tanh = sinh/cosh; soddisfano cosh² − sinh² = 1 e sono l'analogo "iperbolico" di seno e coseno.

- $\cosh$ pari, $\ge 1$ (la **catenaria**); $\sinh$ dispari, strettamente crescente; $\tanh$ dispari, crescente, $|\tanh| < 1$.
- $\cosh^2 x - \sinh^2 x = 1$ (iperbole $x^2 - y^2 = 1$).
- Derivate: $\sinh' = \cosh$, $\cosh' = \sinh$, $\tanh' = 1 - \tanh^2$.
- Inverse: $\operatorname{arsinh} y = \ln(y + \sqrt{y^2+1})$, $\operatorname{arcosh} y = \ln(y + \sqrt{y^2-1})$, $\operatorname{artanh} y = \frac12\ln\frac{1+y}{1-y}$.
- Lunghezza della catenaria: $\int_a^b \cosh = \sinh b - \sinh a$.
- Con Eulero: $\cos\vartheta = \frac{e^{i\vartheta} + e^{-i\vartheta}}{2}$, stessa struttura di $\cosh$.
