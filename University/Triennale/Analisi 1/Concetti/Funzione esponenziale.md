# Funzione esponenziale

> [!summary] In breve
> a^x (a > 0) si definisce per x reale come limite di a^(rₙ) con rₙ razionali; e^x è l'unica funzione (a meno di costanti) uguale alla propria derivata.

- **Definizione**: per $r = \frac pq$, $a^r = \sqrt[q]{a^p}$; per $r \in \mathbb{R}$, $a^r = \lim a^{r_n}$ con $r_n \to r$ (troncamenti decimali).
- Regole: $a^r a^s = a^{r+s}$, $(a^r)^s = a^{rs}$, $a^r b^r = (ab)^r$.
- $a^x$ crescente per $a > 1$, decrescente per $0 < a < 1$; sempre $> 0$; $a^0 = 1$.
- $(e^x)' = e^x$, $(a^x)' = \ln(a)\, a^x$; $a^x = e^{x\ln a}$.
- $e^x = \sum \frac{x^k}{k!}$; $\frac{e^x - 1}{x} \to 1$; $e^x \ge 1 + x$.
- Inversa: il [[Logaritmo]].
