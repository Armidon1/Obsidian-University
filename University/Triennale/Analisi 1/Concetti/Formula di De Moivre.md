# Formula di De Moivre

> [!summary] In breve
> [ρ(cos ϑ + i sin ϑ)]ⁿ = ρⁿ(cos nϑ + i sin nϑ): per elevare a potenza un complesso si eleva il modulo e si moltiplica l'argomento.

$$z^n = \rho^n\big(\cos(n\vartheta) + i\sin(n\vartheta)\big) \qquad (\text{cioè } (\rho e^{i\vartheta})^n = \rho^n e^{in\vartheta})$$

- Esempio: $(1 + i)^7 = (\sqrt2)^7\left(\cos\frac{7\pi}4 + i\sin\frac{7\pi}4\right) = 8 - 8i$.
- **Formula di Eulero**: $e^{i\vartheta} = \cos\vartheta + i\sin\vartheta$; $\cos\vartheta = \frac{e^{i\vartheta} + e^{-i\vartheta}}2$, $\sin\vartheta = \frac{e^{i\vartheta} - e^{-i\vartheta}}{2i}$.
- È la base per le [[Radici n-esime complesse]].
