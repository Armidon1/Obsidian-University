# Successione

> [!summary] In breve
> Una funzione a : ℕ → ℝ, scritta (aₙ); si studia il suo comportamento per n → +∞. Può essere data da una formula o per ricorrenza.

- Notazione: $a_n := a(n)$, $(a_n)_{n \in \mathbb{N}}$.
- Il dominio può essere $\{n_0, n_0 + 1, \dots\}$ se la formula non ha senso per qualche $n$.
- Definizione **per ricorrenza**: $x_{n+1} = g(x_n)$ (es. metodo di Erone).
- Successioni modello: $q^n$ (geometrica), $n^\alpha$ (armonica), $\left(1 + \frac1n\right)^n$.
- **Monotona**: crescente ($a_{n+1} \ge a_n$) o decrescente.
