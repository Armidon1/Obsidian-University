# Curve di livello

> [!summary] In breve
> Γ_c = {x : f(x) = c}: l'insieme dove f vale c (isobare, curve topografiche). Stanno nello spazio del dominio, quindi si "guadagna" una dimensione rispetto al grafico.

| $f$ | Curve di livello |
|---|---|
| $x^2 + y^2$ | circonferenze di raggio $\sqrt c$ |
| $x^2 - y^2$ | iperboli (e le bisettrici per $c = 0$) |

- Possono essere vuote ($x^2 + y^2 = -1$).
- Il [[Gradiente]] è **ortogonale** alle curve di livello e punta verso i livelli crescenti.
