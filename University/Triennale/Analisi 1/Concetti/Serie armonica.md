# Serie armonica

> [!summary] In breve
> Σ 1/k diverge, anche se 1/k → 0; più in generale Σ 1/k^α converge se e solo se α > 1.

$$\sum_{k=1}^{+\infty} \frac1k = +\infty, \qquad \sum_{k=1}^{+\infty} \frac{1}{k^\alpha} \text{ converge} \iff \alpha > 1$$

- Dimostrazione della divergenza: blocchi di $2, 4, 8, \dots$ termini, ognuno $\ge \frac12$.
- Diverge lentissimamente: $s_n \approx \ln n + 0{,}577$ (servono 12.367 termini per superare 10).
- Applicazione: la **scala autoportante** supera qualsiasi distanza.
- $\sum \frac1{k^2} = \frac{\pi^2}{6}$ (Basilea); $\sum \frac{(-1)^k}{k} = -\ln 2$ (Leibniz).
- Il caso $1 < \alpha < 2$ si dimostra con il [[Criterio integrale per le serie]]; $\zeta(s) = \sum k^{-s}$ è la zeta di Riemann.
