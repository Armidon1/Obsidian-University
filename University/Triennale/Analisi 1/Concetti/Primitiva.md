# Primitiva

> [!summary] In breve
> G è una primitiva di f se G' = f; due primitive differiscono per una costante, quindi ∫ f(x) dx = G(x) + c (integrale indefinito).

| $\int f$ | primitiva |
|---|---|
| $x^r$ ($r \neq -1$) | $\frac{x^{r+1}}{r+1}$ |
| $\frac1x$ | $\ln\lvert x\rvert$ |
| $e^x$ | $e^x$ |
| $\sin x$ | $-\cos x$ |
| $\cos x$ | $\sin x$ |
| $\frac{1}{1+x^2}$ | $\arctan x$ |
| $\frac{\varphi'}{\varphi}$ | $\ln\lvert\varphi\rvert$ |
| $\ln x$ | $x\ln x - x$ |

- Unicità a meno di costanti: viene dalla caratterizzazione delle funzioni costanti (su un intervallo!).
- Metodi: [[Integrazione per parti]], [[Integrazione per sostituzione]], [[Integrazione di funzioni razionali]].
