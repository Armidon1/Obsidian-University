# Numeri complessi

> [!summary] In breve
> ℂ è ℝ² con il prodotto (a, b)(c, d) = (ac − bd, ad + bc); scritto a + ib con i² = −1, contiene ℝ ed è algebricamente chiuso.

- **Forma algebrica**: $z = a + ib$, $\operatorname{Re} z = a$, $\operatorname{Im} z = b$; si calcola come con i polinomi usando $i^2 = -1$.
- **Coniugato** $\bar z = a - ib$; **modulo** $|z| = \sqrt{a^2 + b^2}$; $z\bar z = |z|^2$, $\frac1z = \frac{\bar z}{|z|^2}$.
- **Piano di Gauss**: $z \leftrightarrow (a, b)$; somma = somma di vettori.
- **Forma trigonometrica/esponenziale**: $z = \rho(\cos\vartheta + i\sin\vartheta) = \rho e^{i\vartheta}$.
- Prodotto: moduli si moltiplicano, argomenti si sommano.
- **Teorema fondamentale dell'algebra**: un polinomio di grado $n$ ha $n$ radici in $\mathbb{C}$.
