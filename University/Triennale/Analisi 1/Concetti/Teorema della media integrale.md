# Teorema della media integrale

> [!summary] In breve
> Se f ∈ C[a, b], esiste c ∈ [a, b] con ∫ₐᵇ f = f(c)(b − a): f assume il suo valor medio.

$$\frac{1}{b - a}\int_a^b f(x)\,dx = f(c)$$

- Dimostrazione: $m(b-a) \le \int f \le M(b-a)$ (Weierstrass) + valori intermedi.
- È il passo chiave del [[Teorema fondamentale del calcolo integrale]].
- Il valor medio è l'analogo continuo della media aritmetica (e del valore atteso).
