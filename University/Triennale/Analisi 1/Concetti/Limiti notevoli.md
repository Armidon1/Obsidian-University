# Limiti notevoli

> [!summary] In breve
> I limiti fondamentali da cui si ricavano gli altri: sin x/x → 1, (1 − cos x)/x² → 1/2, (eˣ − 1)/x → 1, ln(1+x)/x → 1, (1 + 1/n)ⁿ → e.

| Limite ($x \to 0$) | Valore | Equivale a |
|---|---|---|
| $\frac{\sin x}{x}$ | $1$ | $\sin x \sim x$ |
| $\frac{1 - \cos x}{x^2}$ | $\frac12$ | $1 - \cos x \sim \frac{x^2}{2}$ |
| $\frac{e^x - 1}{x}$ | $1$ | $e^x - 1 \sim x$ |
| $\frac{a^x - 1}{x}$ | $\ln a$ | |
| $\frac{\ln(1 + x)}{x}$ | $1$ | $\ln(1+x) \sim x$ |
| $\frac{(1 + x)^r - 1}{x}$ | $r$ | $(1+x)^r - 1 \sim rx$ |

Inoltre $\left(1 + \frac tx\right)^x \to e^t$ ($x \to \pm\infty$), $x^x \to 1$ ($x \to 0^+$). Sono i primi termini degli sviluppi di [[Formula di Taylor|Taylor]].
