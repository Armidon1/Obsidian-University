# Valore assoluto

> [!summary] In breve
> |x| = x se x ≥ 0, −x se x < 0; |x − y| è la distanza tra x e y sulla retta, ed è lo strumento per dire che due numeri sono "vicini".

- $|x| \ge 0$, $|x| = 0 \iff x = 0$, $|xy| = |x||y|$.
- $|x| < l \iff -l < x < l$ (es. $|x - 3| < 1 \iff 2 < x < 4$).
- **Disuguaglianza triangolare**: $|x + y| \le |x| + |y|$; inoltre $\big||x| - |y|\big| \le |x - y|$.
- Continua ma **non derivabile** in $0$ (spigolo: $f'_\pm(0) = \pm1$).
- In più dimensioni è sostituito dalla [[Norma euclidea]]; nei complessi dal modulo $\sqrt{a^2 + b^2}$.
