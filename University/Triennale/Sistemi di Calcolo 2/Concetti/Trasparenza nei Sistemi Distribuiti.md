# Trasparenza nei Sistemi Distribuiti

> [!summary] In breve
> Nascondere la distribuzione per dare l'immagine di un unico sistema: accesso, locazione, concorrenza, replicazione, guasti, migrazione, prestazioni, scalabilità, parallelismo.

| Trasparenza di… | L'utente non vede… |
| --- | --- |
| accesso | la differenza tra risorse locali e remote |
| locazione | dove si trovano le risorse |
| concorrenza | gli altri utenti |
| replicazione | le copie |
| guasti | i guasti di hardware e software |
| migrazione | lo spostamento delle risorse |
| prestazioni / scalabilità | le riconfigurazioni e la crescita |
| parallelismo | il parallelismo (il "santo graal") |
