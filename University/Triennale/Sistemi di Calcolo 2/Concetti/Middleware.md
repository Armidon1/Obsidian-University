# Middleware

> [!summary] In breve
> Livello software tra le applicazioni e la piattaforma (OS + hardware) che si estende su più macchine e offre API uniformi per accedere alle risorse ovunque si trovino.

- Problemi: eterogeneità, asincronia locale e di rete, mancanza di conoscenza globale e di ordine degli eventi, guasti e partizioni, consistenza vs disponibilità (CAP).
- Forme: Message-Oriented Middleware, RPC, object request broker.
