# Internet of Things

> [!summary] In breve
> Interconnessione di miliardi di oggetti smart, dagli elettrodomestici ai sensori minuscoli, di solito tramite il cloud. Evoluzione: IT → OT → personal technology → sensori/attuatori.

- Tagging, feeling, shrinking, thinking things.
- Livelli: smart things network (milioni, ms) → fog → core network → cloud (centinaia).
- Applicazioni: casa, trasporti, salute, edifici, città (smart parking, rifiuti, mucche connesse…).
- Critiche: privacy, sicurezza, controllo sociale, impatto ambientale.
