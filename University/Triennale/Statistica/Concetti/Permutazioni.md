# Permutazioni

> [!summary] In breve
> Modi di ordinare tutti gli $n$ elementi di un insieme: disposizioni con $k=n$.

| | Formula |
|---|---|
| Semplici | $P_n=n!$ |
| Circolari | $P^c_n=(n-1)!$ |
| Con ripetizione ($n_1+\dots+n_k=n$) | $\dfrac{n!}{n_1!\cdots n_k!}$ (coefficiente multinomiale) |

- Esempio: anagrammi di MAMMA $=\frac{5!}{3!\,2!}=10$.
