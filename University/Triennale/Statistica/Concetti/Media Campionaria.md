# Media Campionaria

> [!summary] In breve
> $\bar X_n=\frac1n\sum_{k=1}^nX_k$: v.a. con la stessa media $\mu$ delle $X_k$ e varianza $\sigma^2/n$.

- È una **stima** di $\mu$ che fluttua; il valore atteso è invece un numero fisso.
- $E[\bar X_n]=\mu$, $\mathrm{Var}(\bar X_n)=\frac{\sigma^2}n$ (se le $X_k$ sono indipendenti o incorrelate).
- Per il TLC, $\bar X_n\;\dot\sim\;N(\mu,\sigma^2/n)$.
