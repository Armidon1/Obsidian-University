# Tesi di Church-Turing

> [!summary] In breve
> Ogni funzione calcolabile mediante un algoritmo (con qualunque approccio formale) è calcolabile da una macchina di Turing. È una tesi, non un teorema: "algoritmo" non è un concetto formale.

Sostenuta dall'equivalenza di tutti i modelli proposti:

| modello | autore |
|---|---|
| $\lambda$-calcolo | Church (1936) |
| funzioni ricorsive | Kleene (1936) |
| sistemi di riscrittura | Post (1943) |
| algoritmi di Markov | Markov (1949) |
| macchine a registri (RAM) | Shepherdson e Sturgis (1963) |

Conseguenza: la terminazione è indecidibile in **ogni** linguaggio di programmazione. Non dice che tutti i modelli eguagliano le MT: gli ASF, per esempio, sono più deboli.
