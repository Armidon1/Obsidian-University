# Insieme numerabile

> [!summary] In breve
> Un insieme è numerabile se è equinumeroso a $\mathbb{N}$ (cardinalità $\aleph_0$): i suoi elementi si possono elencare in una lista infinita. È **contabile** se è finito o numerabile.

**Numerabili**: $\mathbb{N}$, $\mathbb{Z}$, $\mathbb{N}^2$, $\mathbb{Q}$, $\Sigma^*$, l'insieme dei **programmi**, le unioni contabili di insiemi contabili.

Funzione coppia di Cantor (enumerazione per diagonali):
$$p(i, j) = \frac{(i+j)(i+j+1)}{2} + i$$

**Non numerabili**: $\mathbb{R}$, $\mathcal{P}(\mathbb{N})$, le funzioni $\mathbb{N} \to \{0, 1\}$ (cardinalità $2^{\aleph_0}$), quindi i **problemi di decisione**.
