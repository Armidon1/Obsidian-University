# Git

> [!summary] In breve
> Sistema di controllo di versione distribuito usato per distribuire e versionare il codice del corso.

- La storia è un **grafo aciclico di commit**: ogni commit è uno snapshot completo del progetto che punta al commit padre; un branch è un puntatore a un commit.
- Comandi essenziali: `clone`, `status`, `diff`, `add`, `commit -m`, `pull`, `push`, `log`.
- Riferimenti: Git tutorial, *Pro Git book*, *Git for computer scientists*.
