# JSON

> [!summary] In breve
> Formato testuale per lo scambio di dati: documenti tra graffe con coppie nomeCampo: valore, dove il valore può essere numero, stringa, booleano, array o documento annidato.

```json
{ "nome": "Mario", "eta": 45, "impiegato": false,
  "telefono": ["0243434", "064334343"],
  "indirizzo": { "citta": "bologna", "via": "po", "numero": 3 } }
```
Valori non atomici (array, documenti): impossibili nel modello relazionale.
