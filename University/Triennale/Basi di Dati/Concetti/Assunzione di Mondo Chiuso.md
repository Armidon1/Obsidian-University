# Assunzione di Mondo Chiuso

> [!summary] In breve
> Se una tupla non è nella base di dati, il fatto che rappresenterebbe è falso.

- È l'assunzione implicita delle basi di dati (*closed world assumption*).
- Giustifica le query con negazione: "artisti che non hanno suonato a Napoli" secondo quanto registrato.
- L'alternativa (mondo aperto: assente = sconosciuto) è fuori dal corso.
