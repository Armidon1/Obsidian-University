# DBMS

> [!summary] In breve
> Data Base Management System: il software che gestisce collezioni di dati grandi, persistenti e condivise, garantendo affidabilità, privatezza, efficienza ed efficacia.

| Dati | Garanzie |
|---|---|
| **grandi** (più della RAM) | **affidabilità** (guasti) |
| **persistenti** (oltre i programmi) | **privatezza** (controllo accessi) |
| **condivisi** (più applicazioni) | **efficienza**, **efficacia** |

- Ai dati si accede **solo tramite il DBMS** (livello dei dati dell'architettura a tre livelli).
- Ogni DBMS si basa su un **modello dei dati**: nel corso il [[Modello Relazionale]].
