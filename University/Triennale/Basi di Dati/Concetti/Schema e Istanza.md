# Schema e Istanza

> [!summary] In breve
> Lo schema descrive la struttura (livello intensionale, stabile); l'istanza è il contenuto in un certo istante (livello estensionale, variabile).

| | Schema | Istanza |
|---|---|---|
| relazione | $R(A_1, \dots, A_n)$ | insieme di tuple su $\{A_1, \dots, A_n\}$ |
| base di dati | insieme di schemi di relazione | un'istanza per ogni schema |

Vale anche nel modello ER: lo schema ha entità/relazioni, le istanze oggetti e tuple.
