# NoSQL

> [!summary] In breve
> Movimento e famiglia di DBMS non relazionali (Not Only SQL): distribuiti, scalabili orizzontalmente, spesso senza schema, senza join e senza ACID.

| Modello | Esempio |
|---|---|
| chiave/valore | Redis |
| document-oriented | MongoDB |
| column-oriented | Cassandra |
| graph-oriented | Neo4j |

Si sacrificano rigidità, join e ACID per scalabilità e flessibilità.
