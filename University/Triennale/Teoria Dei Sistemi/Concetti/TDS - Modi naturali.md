# TDS - Modi naturali

> [!summary] In breve
> Le componenti elementari dell\'evoluzione libera: una legge temporale ($e^{\lambda t}$, $e^{\alpha t}\sin$, $t^ke^{\lambda t}$) lungo una direzione o un piano dello spazio di stato.

- Autovalore reale → modo **aperiodico** $c\,e^{\lambda t}u$ (retta di $u$).
- Coppia complessa → **un** modo **pseudoperiodico** nel piano $(u_a,u_b)$.
- Jordan → leggi $t^ke^{\lambda t}$ fino all'indice geometrico − 1.
- Discreto: $\lambda^t$ (alternante se $\lambda<0$).
- Convergono se $\mathrm{Re}\,\lambda<0$ (continuo) o $|\lambda|<1$ (discreto).
