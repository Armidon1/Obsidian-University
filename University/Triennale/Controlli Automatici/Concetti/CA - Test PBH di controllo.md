# Test PBH di controllo

> [!summary] In breve
> Il test sui modi critici è $\operatorname{rank}[\lambda I-A\ B]=n$ per $\Re\lambda\ge0$.

Se vale per tutti gli autovalori dà raggiungibilità, se vale solo sui critici dà stabilizzabilità.
