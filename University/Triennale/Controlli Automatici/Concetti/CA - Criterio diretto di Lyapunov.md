# Criterio diretto di Lyapunov

> [!summary] In breve
> Una candidata DP con derivata non positiva prova stabilità; con derivata DN prova AS localmente.

Sono condizioni sufficienti per la candidata scelta. Il fallimento di un tentativo non dimostra instabilità.
