# Causalità

> [!summary] In breve
> Un sistema causale usa dati presenti e passati; una FdT razionale propria ammette una realizzazione ordinaria causale.

Un derivatore ideale richiede un trattamento non realizzabile come blocco proprio ordinario. Il filtro di implementazione cambia il progetto.
