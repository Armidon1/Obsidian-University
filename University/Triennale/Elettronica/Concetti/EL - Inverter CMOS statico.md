# Inverter CMOS statico

> [!summary] In breve
> Gate comuni all’ingresso. Ingresso basso: n OFF, p ON, uscita alta. Ingresso alto: p OFF, n ON, uscita bassa. Nei livelli estremi ideali non scorre corrente continua tra le alimentazioni.
