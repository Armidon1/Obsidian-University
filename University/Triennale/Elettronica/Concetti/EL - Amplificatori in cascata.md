# Amplificatori in cascata

> [!summary] In breve
> $A_{tot}=\prod_k A_k$ se i guadagni includono i carichi degli stadi successivi. In dB i guadagni si sommano. I buffer separano le impedenze.

## Ripasso attivo

- Quali guadagni si possono moltiplicare senza introdurre altri fattori di carico?
